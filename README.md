# Personal-website-project

A personal website project built from a Figma design and developed using HTML, CSS, and JavaScript.

**Work in Progress** — the website is currently being developed and additional features and responsive improvements are still being added.

## Technologies

* HTML
* CSS
* JavaScript
* Figma
* Git & GitHub

## Current Features

* Welcome page
* Interactive quiz-based login
* Access Granted / Access Denied pages
* Interactive buttons with visual feedback
* Personal website content
